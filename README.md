## Dense broadsheet for 22 November 2026

This entry packs 36 dated stories for Sunday 22 November 2026 into one dense broadsheet image, drawn programmatically with no external assets, fonts, or images, and fully deterministic so repeated runs produce byte-identical output: a giant date masthead, three main cards, ten secondary cards, a numbered ALSO ON list for the remaining stories, a DATE CHECK box, a UTC timeline strip, a stories-by-region count, a pinned world map, and a day-in-numbers strip, with every story labelled CONFIRMED, REPORTED, or CLAIM.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
